# LiteNotes

A quiet notebook for the web. One typeface, a numbered list, and a note that slides up over it.

- Write, highlight, and flag notes
- Search by name or date (`19.10`, `2026-10`, `october`)
- Photos become small black-and-white dithered images
- Light and dark mode
- Works offline; install it from Safari with **Share → Add to Home Screen**

Notes and photos are stored only in your browser on your device (IndexedDB). Nothing is sent anywhere.

Plain HTML, CSS and JavaScript, no build step. Font: [Overpass](https://overpassfont.org) (SIL Open Font License).
